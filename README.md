# БК «Меридиан» — сайт баскетбольного клуба

База проекта: каркас, модель данных клуба и логика расчётов. Визуальная и остальная
техническая часть добавляются поверх этой основы.

## Стек

- Node.js 20+, Vite 7, React 19, TypeScript 5.9
- Tailwind CSS 3.4.19 + токены темы (shadcn, стиль `new-york`)
- shadcn/ui-совместимые примитивы в `src/components/ui`
- Алиас `@` → `src`

## Команды

```bash
npm install     # установка зависимостей
npm run dev     # dev-сервер на http://localhost:3000
npm run build   # tsc -b + vite build
npm run lint    # eslint
npm run preview # предпросмотр собранной версии
```

## Сцена броска на прокрутке

Секция `HoopSequence` — закреплённый экран высотой `320svh`. Пока идёт прокрутка
внутри неё, сцена удерживается и разворачивается по сценарию: выезжает кольцо,
в него по дуге влетает мяч, кольцо вместе с мячом уходит и открываются кадры
с матчей. Прокрутка вверх проигрывает всё в обратном порядке.

Как это устроено:

- фазы заданы числами в `src/hooks/useScrollProgress.ts` (`PHASE`) — порядок фаз
  и есть сценарий;
- прогресс секции пишется прямо на её элемент как CSS-переменные (`--hoop-in`,
  `--ball-x`, `--photo` и др.), поэтому React не перерисовывается ни на один кадр;
- анимируются только `transform` и `opacity`, так что кадр собирает композитор;
- при `prefers-reduced-motion: reduce` сцена отключается, галерея показывается сразу.

Важно: у `body` стоит `overflow-x: clip`, а не `hidden`. `hidden` превращает body
в контейнер прокрутки и ломает `position: sticky`, на котором держится сцена.

Фотографии лежат в `public/photos` (`match-01…04.jpg`, 612×408), подписи —

под неё же подогнаны исходники.

## Тема оформления

Переключатель темы — кнопка в шапке страницы (`ThemeToggle`). Три режима по кругу:

1. **Светлая** — принудительно светлая;
2. **Тёмная** — принудительно тёмная;
3. **Как в системе** — следует за настройкой ОС.

Как это устроено:

- `src/lib/theme.ts` — типы, ключ хранилища и чистые функции: чтение выбора,
  применение к документу, сведение выбора с системной темой;
- `src/components/ThemeProvider.tsx` — хранит выбор, пишет класс `.dark` на `<html>`
  и реагирует на смену системной темы через `useSyncExternalStore`;
- `src/hooks/useTheme.ts` — контекст и хук `useTheme()` для доступа к теме;
- токены обеих тем лежат в `src/index.css` (`:root` и `.dark`), Tailwind
  переключается директивой `darkMode: ["class"]` в `tailwind.config.js`.

Выбор сохраняется в `localStorage` под ключом `meridian-theme`. Чтобы не было
вспышки светлой темы при загрузке, тот же ключ читает и применяет маленький
инлайн-скрипт в `index.html` — он выполняется до отрисовки. **Если меняете ключ
или значения `--paper`, поправьте их и в скрипте**: `THEME_STORAGE_KEY` в
`src/lib/theme.ts` и `THEME_COLOR` там же.

Добавить свой переключатель можно через хук:

```tsx
const { theme, resolvedTheme, setTheme, toggleTheme } = useTheme();
```

## Как менять контент

Контент отделён от разметки: всё содержимое правится в `src/data/team.ts`.

- `club`, `arena` — реквизиты клуба и домашняя площадка
- `players`, `coaches` — заявка и тренерский штаб
- `games` — календарь; у сыгранного матча заполнены `quarters`, `scored`, `conceded`,
  у будущего они отсутствуют
- `standings` — турнирная таблица, у своей команды `isUs: true`
- `news`, `partners`, `navLinks`

Формат дат в `games` и `news` — ISO с часовым поясом, например
`2026-10-04T18:30:00+03:00`. Форматированием занимается `src/lib/team.ts`,
поэтому даты в разметке не хардкодятся.
